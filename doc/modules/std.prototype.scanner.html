Module std.prototype.scanner

Scanner Prototype.

This module returns a table of scanner helpers, as well as the prototype for a Scanner object.

A Scanner reads a string of text one character at a time, for the lexer of a parser to build its tokens from. It always knows where the next character is, and peek looks at characters that are not read yet, next reads them, back unreads them, and take, skip and match read a whole run of them in one call.

Classes of character are sets, which join with +, and make a lexer read like its grammar:

local Scanner = require 'std.prototype.scanner'.prototype
local charset = require 'std.prototype.scanner'.charset

local isspace = charset ' \t\r\n'
local isdelimiter = charset '()"' + isspace

local scanner = Scanner('(add 1 2)', 'sum.lsp')
scanner:next()                      --> '('
scanner:take(function(c)            --> 'add'
   return not isdelimiter[c]
end)
scanner:skip(isspace)
scanner:match '%d+'                 --> '1'
scanner:error 'unexpected end'      --> error: sum.lsp:1: unexpected end

An index is the position of a character in the text, counting from 1. Where the cursor stands is the index of the next character to read, so pos is 1 before anything is read and one more than the length of the text at the end.

In addition to the functionality described here, Scanner objects also have all the methods and metamethods of the prototype.object.prototype (except where overridden here).

Initialisation

prototype._init
Scanner object initialisation.

Returns a Scanner for text, with the cursor at the start. A table, as a type derived from this one is described with, has any field with a leading underscore, such as _type, put in the metatable, and no other fields.

Parameters:

  • new table uninitialised Scanner container object
  • text string the text to scan
  • name string what to call the source of text in errors (optional)

prototype:match (pattern)
Read what a Lua pattern matches, if it matches next. The pattern is matched as if it started with ^, from the cursor.

prototype:take (set)
Read the run of characters that are in a class.

Parameters:

prototype:line ([index])
The line number of an index in the text. The first line is 1. Line numbers are not counted until asked for, so they cost nothing to a scanner that is never asked.

Parameters:

  • index integer defaults to the cursor (optional)

Returns:

    int the line that the character at index is on

Usage:

    local l = scanner:line()
prototype:error (msg[, index])
Raise an error that says where in the text it is. The message is name:line: msg, or line: msg for a scanner with no name, and has no Lua position added to it.

Parameters:

  • msg string what is wrong
  • index integer defaults to the cursor (optional)

Usage:

    scanner:error "missing ')'"
